Self-hosted companion app that suggests matches between Invoice Ninja expenses and Paperless-ngx documents, then writes cross-links into your existing custom fields. You confirm every link.

Selbst gehostete Begleit-App, die Zuordnungen zwischen Invoice-Ninja-Ausgaben und Paperless-ngx-Dokumenten vorschlägt und Querverweise in deine vorhandenen Custom Fields schreibt. Du bestätigst jeden Link.

mkdir paperninja && cd paperninja && curl -fsSL -O https://raw.githubusercontent.com/shrippen/PaperNinja/main/docker-compose.yml

Then copy .env.example to .env, set your tokens and run docker compose up -d.

Danach .env.example nach .env kopieren, deine Tokens eintragen und docker compose up -d ausführen.

Up and running in 3 minutes

In 3 Minuten startklar

Docker Compose, two API tokens, done.

Docker Compose, zwei API-Tokens, fertig.

  1. Pull & configure — grab docker-compose.yml and .env.example, set your Invoice Ninja and Paperless URLs & tokens.
  2. Start the container — run docker compose up -d. Open localhost:8080 and set your app password.
  3. Map custom fields — the Setup / Fields screen auto-discovers both APIs. Copy the suggested ENV lines and restart.
  4. Start linking — review suggestions on To link, confirm matches, and see cross-links appear in both systems instantly.
  1. Holen & konfigurieren – docker-compose.yml und .env.example laden, URLs und Tokens von Invoice Ninja und Paperless eintragen.
  2. Container starten – docker compose up -d ausführen, localhost:8080 öffnen und das App-Passwort setzen.
  3. Custom Fields zuordnen – der Bildschirm Setup / Fields erkennt beide APIs automatisch. Vorgeschlagene ENV-Zeilen kopieren und neu starten.
  4. Verknüpfen – Vorschläge unter To link prüfen, Treffer bestätigen und die Querverweise erscheinen sofort in beiden Systemen.
