Self-hosted companion app that suggests matches between Invoice Ninja expenses and Paperless-ngx documents, then writes cross-links into your existing custom fields.

Get started ★ GitHub

Why PaperNinja?

Both systems already store your data. PaperNinja just connects them — live, transparent, and under your control.

🔍

Smart scoring

Amount, date, vendor fuzzy match and invoice number — each signal scored and explained in the UI.

☑

Human-in-the-loop

Every link requires your confirmation. No auto-link, no silent overwrites. Ignore false positives with one click.

🔄

No matching database

All state lives in Invoice Ninja & Paperless. PaperNinja reads and writes via their APIs — nothing to migrate.

📑

1∶n combined receipts

One bank charge covering multiple receipts? Optional sum-search finds document sets that add up to the expense.

🏠

Self-hosted & private

Single Docker container (Alpine, ~50 MB). API tokens stay on your server, behind your auth.

🌐

German & English

Full UI translation including score details. Keyboard shortcuts for power users.

Up and running in 3 minutes

Docker Compose, two API tokens, done.

Pull & configure

Grab docker-compose.yml and .env.example, set your Invoice Ninja and Paperless URLs & tokens.

Start the container

Run docker compose up -d. Open localhost:8080 and set your app password.

Map custom fields

The Setup / Fields screen auto-discovers both APIs. Copy the suggested ENV lines and restart.

Start linking

Review suggestions on To link, confirm matches, and see cross-links appear in both systems instantly.

# Quick start mkdir paperninja && cd paperninja curl -fsSL -o docker-compose.yml \ https://raw.githubusercontent.com/shrippen/PaperNinja/main/docker-compose.yml cp .env.example .env # set tokens docker compose up -d

Architecture

One process, no SPA build, no matching database. Reads and writes go straight to the source APIs.
